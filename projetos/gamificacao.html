SOBRE O PROJETO

Conceito

O projeto reúne diferentes experiências de jogo em uma aplicação com foco em atenção e concentração. A ideia é utilizar mecânicas simples para observar o desempenho do jogador em diferentes situações.

DESAFIO

O que estou resolvendo

Um dos desafios é transformar conceitos de atenção em mecânicas objetivas, mantendo a experiência simples o suficiente para que o jogador entenda rapidamente o que precisa fazer.

MINHA CONTRIBUIÇÃO

O meu papel

Desenvolvimento dos protótipos, programação das mecânicas, estruturação da aplicação e definição dos elementos de interação.
