# Guilherme Silva — Game Dev Portfolio

Versão completa do portfólio, pronta para GitHub Pages.

## O que foi incluído

- Header fixo com menu responsivo
- Foto de perfil
- Hero com identidade visual própria
- Carrossel automático de projetos a cada 5 segundos
- Vídeos opcionais dos projetos
- Seção "O que eu faço"
- Seção "Currently working on"
- Experiência resumida na Home
- Página de projetos
- Case study individual para cada projeto
- Página Sobre
- Página Contato
- GitHub e LinkedIn
- Animações leves no scroll
- Hover/interações nos cards
- Favicon usando a foto de perfil
- Meta description e Open Graph básico
- Layout responsivo para celular
- Estrutura organizada para GitHub Pages

## Vídeos

Coloque na pasta `assets/videos/`:

- `boo.mp4`
- `gamificacao.mp4`
- `semaforo.mp4`

## GitHub

Substitua `https://github.com/` e `github.com/SEU-USUARIO` pelo seu perfil real.

## Publicação

GitHub → Settings → Pages → Deploy from branch → branch principal → `/root`.
